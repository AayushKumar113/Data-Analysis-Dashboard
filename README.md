#Amazon-Sales-Data-Analysis (Interactive Dashboard creation using MS Excel)

###🔍 Project Description
Interactive Excel dashboard analyzing Amazon’s 2024 sales across 23 Indian cities and states. It features KPIs, sales trends, and a geo-visual map. Built using Excel tools like Pivot Tables, Charts, and conditional formatting.

###🛠️ Tools Used
Microsoft Excel
Pivot Tables
Line & Doughnut Charts
Map Chart
Slicers and Shapes

###⚙️ Steps Performed
1.Data Cleaning & Preparation
Removed blanks and ensured consistent formats
Standardized city/state names for mapping

###2.Data Analysis
Created Pivot Tables to summarize sales, units, and cities
Used Excel formulas for calculating totals

###3.KPI Setup
Total Sales, Units Sold, and City Count
Used Doughnut Charts to show progress (in %)

###4.Visualization
Line Chart for City-wise Sales Trends
Map Chart for State-wise Sales Distribution

###5.Dashboard Design
Added icons, slicers, and a clean layout
Aligned visuals for professional appearance

###📈 Key Metrics
Total Sales: ₹1,02,26,625
Units Sold: 33,874
Cities Covered: 23

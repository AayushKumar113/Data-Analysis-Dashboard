#Amazon-Sales-Data-Analysis (Interactive Dashboard creation using MS Excel)

##🔍 Project Description
Interactive Excel dashboard analyzing Amazon’s 2024 sales across 23 Indian cities and states. It features KPIs, sales trends, and a geo-visual map. Built using Excel tools like Pivot Tables, Charts, and conditional formatting.

## Dataset used
- <a href="https://github.com/AayushKumar113/Data-Analysis-Dashboard/blob/main/Sales%20Data.xlsx">Dataset</a>

##Questions (KPIs)
-What is the total revenue generated in 2024?
-How many total units were sold across all cities?
-How many unique cities contributed to the overall sales?
-Which city recorded the highest sales in 2024?
-Which state had the highest total sales and why might that be the case?
-What percentage of the target revenue was achieved?
-What is the average sales per city?
-Which cities had below-average sales performance?
-How does the sales distribution vary across different cities?
-What percentage of units sold target was achieved?

### 🔄 Project Process
The development of the Amazon Sales Dashboard followed a structured analytical and design process to ensure clarity, accuracy, and visual appeal. Below are the steps involved:

#### 1. 📥 Data Collection
- Gathered sales data from Amazon India for the year 2024.
- Included details such as City, State, Units Sold, and Revenue.

#### 2. 🧹 Data Cleaning & Preparation
- Removed duplicates and null values.
- Standardized formatting for city and state names.
- Ensured numerical fields (Sales, Units) were correctly typed.

#### 3. 📊 Data Analysis
- Used Pivot Tables to compute:
  - Total Sales per City and State
  - Total Units Sold
  - Unique Cities Covered

#### 4. 📌 KPI Setup
- Defined key performance indicators (KPIs):
  - Total Sales
  - Units Sold
  - Cities Covered
- Created Doughnut Charts to represent KPI achievement percentages visually.

#### 5. 📈 Data Visualization
- Designed:
  - **Line Chart** for city-wise sales trends.
  - **Map Chart** for state-wise sales distribution.
  - **Doughnut Charts** for KPI progress tracking.

#### 6. 🧱 Dashboard Design
- Aligned visuals for consistency and readability.
- Used shapes, icons, and slicers to enhance user interaction.
- Created a modern layout with professional styling in Excel.

#### 7. ✅ Final Review
- Verified KPI accuracy against raw data.
- Ensured visual clarity and responsive slicers.
- Saved and exported the dashboard for sharing and presentation.
